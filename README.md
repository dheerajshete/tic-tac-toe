# Tic-Tac-Toe 🎮

A simple and responsive two-player Tic-Tac-Toe game built with **HTML, CSS, and JavaScript**.

## Features

* Two-player gameplay
* Player X and Player O turns
* Automatic win detection
* Draw detection
* Prevents players from selecting an already-used cell
* Displays the winner
* Restart Game button
* Responsive design for smaller screens
* Modern glass-style UI

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Play

1. Player 1 starts with **X**.
2. Player 2 plays with **O**.
3. Players take turns selecting an empty cell.
4. The first player to get three marks in a row wins.
5. If all cells are filled without a winner, the game ends in a draw.
6. Click **Restart Game** to start a new game.
